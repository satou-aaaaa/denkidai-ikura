# 電気代いくら？（denkidai-ikura）

ドライヤーを1時間使うと何円？ 家電の W（消費電力）と使う時間から、使った電気の量（kWh）と電気代を計算する1日5問の学習ゲーム。正解したら「どう計算した？」も選びます。

遊ぶ：https://satou-aaaaa.github.io/denkidai-ikura/

- 電気代は「W × 時間 ÷ 1000 × 31円」で計算します（2026-11-17 に読んだ資料）。
  - [全国家庭電気製品公正取引協議会「よくある質問」](https://www.eftc.or.jp/qa/)（電力料金の目安単価 31円/kWh・税込・令和4年7月22日改定）
  - [資源エネルギー庁「省エネポータルサイト 無理のない省エネ節約」](https://www.enecho.meti.go.jp/category/saving_and_new/saving/general/howto/)（同じ 31円/kWh を使う）
- 家電の W・使う時間は練習用の作り話です。実物の家電の数字ではありません。本当の電気代は、契約している電力会社の料金で決まります。
